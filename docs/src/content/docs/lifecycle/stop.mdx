---
title: When Claude stops
description: The Stop hook and the checks it runs on the turn's changes.
---

When you send a prompt, `claude-forge hook user-prompt-submit` snapshots the working tree. When Claude ends its turn, `claude-forge hook stop` compares: if nothing changed during the turn, Claude stops freely. Otherwise it runs the active checks on **what changed during the turn**, commits made during the turn included. Files only you changed are not part of it; a file Claude changed is checked as a whole. If the check fails, the stop is blocked and Claude gets the findings, so it keeps working. After three blocks in a row it hands over to you; a new prompt starts the count again. The project's own checks (tests, type checks) are capped in time; Forge's overhead has a tight budget of its own.

## The steps

The checks run in stages and stop at the first that fails: test integrity, `forbid` rules, format, lint, codegen, typecheck, migrations, tests. `forge check` runs the same steps outside a session.

## Files the change touched

Outside `--all`, every finding in a file the change touched counts, whether Claude brought it or the file already had it: a `forbid` match, a lint finding, a type error, dead code. A finding in a file the change did not touch counts only when the change caused it (a caller it broke, a function whose last call it removed): Forge then runs the check on a copy of the base (the start of the turn, `HEAD` for a commit, the merge base in a pull request) and keeps what is new. Counting rules (`no-increase`, `no-decrease`) compare whole files.

## Failing tests

A failing test blocks, whatever its cause, including a missing database or network, and whether it already failed before the turn. Claude reads the failure as the test run printed it. The Stop limits still apply: after three blocks in a turn, or when Claude stops again without changing anything, it hands over to you.

## Advice

Advisory checks report what Claude may have a reason to leave as it is: each finding blocks Stop once per turn, after any failing check, so Claude acts on it or says why it does not apply. A check that could not run is a note for you, never advice.
