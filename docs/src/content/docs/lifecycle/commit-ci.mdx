`claude-forge check` runs the active rules' checks outside a session. Its output is for people, notes included. Exit codes: 0 passed, 1 failed, 3 nothing failed but a check could not run (unverified), 4 only advice was found, 2 a usage or configuration error; `--json` prints the result as JSON.

## Pre-commit

`forge apply` offers to run `claude-forge check --changed` before each commit. Without a hook manager it creates `.git/hooks/pre-commit`. With one (pre-commit, lefthook, Husky, or `core.hooksPath`), it adds the check to the manager's config as a block between `# forge: begin` and `# forge: end`, and leaves the rest of the file as it was; `forge remove` takes the block out. When the check is not installed, `forge apply` and `forge status` say that commits are not checked.

## CI

On a pull request, run `claude-forge check --since origin/<default branch>`: it checks what the branch changed since its merge base, with the same added-lines rule as Stop. The checkout needs the base branch's history (`fetch-depth: 0`). On the default branch, `claude-forge check --all` checks the whole project.

```yaml
- uses: actions/checkout@<sha>
  with: {fetch-depth: 0, persist-credentials: false}
- run: curl -LsSf https://github.com/mde-pach/claude-forge/releases/latest/download/install.sh | sh
- run: claude-forge check --since "origin/$BASE_REF"
  if: github.event_name == 'pull_request'
  env: {BASE_REF: "${{ github.base_ref }}"}
- run: claude-forge check --all
  if: github.event_name != 'pull_request'
```

The installed launcher runs the version `forge.lock` records.
