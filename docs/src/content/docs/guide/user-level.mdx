import Spec from "../../../components/Spec.astro";

`forge apply --user` writes a `forge-user` plugin under `~/.claude/skills/` — a guard on Bash commands and terminal notifications — and appends the [safety](../../packs/safety/) pack's permissions and sandbox settings to `~/.claude/settings.json`. These protect every project you open, whether or not it uses Forge.
