---
title: User level
description: What forge apply --user writes to ~/.claude, once per machine.
---

`forge apply --user` appends the [safety](../../packs/safety/) pack's permissions and sandbox settings, and the hook entries for the user-level guard, to `~/.claude/settings.json`, and records them in the user-level lock. These protect every project you open, whether or not it uses Forge. `forge status --user` shows them, and `forge remove --user` takes out exactly what the lock records.
