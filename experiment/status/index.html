Why the run is slow

  • Each trial pays for a full project setup twice. The agent gets a freshly installed container, and its diff is scored in a second fresh one, so it cannot tamper with the tests or the environment. That is 1–3 minutes for the Python repos and zod, and 15–25 minutes for better-auth, whose tests need the whole monorepo built.
  • better-auth dominates. It is 1 trial in 6 but takes about half of all machine time.
  • Forge makes its arm slower by design. Its Stop hook runs the project's checks and related tests before the agent may finish, and sends it back to work (up to 3 times) until they pass. Agent time in the Forge arm is several times the baseline's on zod, pydantic-ai and better-auth.
  • The machine is small. It has 4 CPUs and about 11 GB of free disk, and each workspace takes 1.5–3.5 GB, so only 3 trials run at once and the CPUs are saturated.
